# Teaching without text

Every move or object the player must use goes through four steps, usually one room each:

1. **Show it safely.** The player meets it where failure costs nothing: a low gap over solid floor, not over spikes. Example: the first double jump is up to a ledge above flat ground.
2. **Use it.** Now it is needed to progress, with mild risk.
3. **Combine it.** Mix it with something already learned, e.g. a double jump right after a long run jump.
4. **Test it.** A room that asks for it with less safety or more precision.

**Rules**

- Never require a move before step 1 has happened.
- One new thing at a time. Don't introduce two moves in the same room.
- Death is a fine teacher only when it is cheap: the room is short and the cause is obvious.
- If a step is hard enough that many players would get stuck, add an easier side room that teaches just that step, and keep it out of the way of players who already get it.
- Text is only for the controls at the very start, if at all.
